# Voter Eligibility Checker

This is a simple web app that checks whether a person is eligible to vote in India.

## What it does

The form asks for:
- Full name
- Age
- Nationality

When the user submits the form, the app checks:
- the name is not empty
- the age is at least 18
- the nationality is Indian

Then it shows a success or error message based on the result.

## Files

- `index.html` – page structure
- `style.css` – page styling
- `script.js` – validation and result logic

## How to run

Open `index.html` in a browser to use the app.
